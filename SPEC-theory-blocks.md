# THEORY BLOCKS — spec v1 (trojan horse model)

Premise: joke blocks carry theory blocks. The audience comes for the dopey
character, leaves with recognition theory. Comedy is the guise; analysis is
the payload. Same trick the ultraterrestrials use, aimed better.

## 1. Theory block format (mirrors joke beats)

A theory block is one speakable unit, ~15-40 words, shaped like the
"what the heck is X" essays (`/root/projects/essayviz-workspace/what-the-heck-is-tetrahedron.md`):
hook-claim → minimum proof sketch → implication. Five slots:

```text
THEORY/{topic}/{n}:
  claim:    one sentence, plain words, no jargon first
  sketch:   smallest supporting move (example, number, image)
  payload:  what it means for the listener (so-what)
  source:   exact file + search term (verify_against discipline)
  carrier:  which character voice it ships in (dopey, deadpan, smug...)
```

Delivery rule: at most 1 theory block per 3 joke blocks. Two in a row
kills the room. The tag after a theory block must be a joke, never a
second theory block.

## 2. Weaving model (per 60s set)

```text
setup (joke) -> punchline (joke) -> tag (joke)
  -> THEORY (one block, carrier voice, ~8 seconds)
  -> tag (joke that reframes the theory as gossip)
  -> closer (joke; theory echoes, never repeated)
```

Dopey-carrier pattern: the least credible voice delivers the sharpest
claim. The audience laughs at the carrier, then the claim lands late —
backseat enlightenment. Example shape: "So I'm basically a... wait.
If I'm aware of being aware, who's... hold on, I need to sit down."

## 5. Flagship sketch: the dopey recognition philosopher

Working name: "Gary Unconstructed." Premise: parking-lot attendant who
achieved the sigma-flip and cannot explain it without drooling. Payload
per set (exactly one): content-unchanged-positioning-flip ("nothing
changed, I just... oh no, there I am"), or the non-constructed I ("the
I that was never built can't break down — watch this"), or Omega ("the
one who knows the order without being caught in it — that's my supervisor.
Dave."). Interview fuel: 5 facts, each a mangled-but-accurate tenet the
interviewer can sharpen live.

## 6. Rules

- No verbatim from copyrighted works on stage or in packs. Ever.
- Every theory block carries source + search term (verify_against).
- PD texts (Steiner 1910, Kirk 1691, Evans-Wentz 1911, Taylor 1816) may be
  quoted briefly with attribution.
- Canon blocks gain a `theory_payloads[]` list; performers reference by id.
- Ratio enforced: >=3 joke blocks per theory block. Funny first, funded by laughs.
